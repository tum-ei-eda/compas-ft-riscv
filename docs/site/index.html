Your first hardened function

From C to
hardened assembly.

Use a COMPAS-enabled LLVM toolchain. Emit LLVM IR with its Clang frontend, then select the protection in llc.

01 / SET UP

Build LLVM with the matching COMPAS integration patch, or use the compiler container.

Installation guide →Container instructions ↗

The example uses RV32IM and selects the exact symbol kernel for both protection layers.

02 / COMPILEshell
# Point to your COMPAS-enabled toolchain.
export COMPAS_LLVM_ROOT="$PWD/build/llvm-build"
mkdir -p build/quickstart
cat > build/quickstart/kernel.c <<'EOF'
unsigned kernel(unsigned x) {
    return (x * 17u) ^ (x >> 3);
}
EOF

# C → LLVM IR
"$COMPAS_LLVM_ROOT/bin/clang" \
  --target=riscv32 -march=rv32im -mabi=ilp32 \
  -O2 -ffreestanding -S -emit-llvm \
  build/quickstart/kernel.c -o build/quickstart/kernel.ll

# LLVM IR → layered, hardened RISC-V assembly
"$COMPAS_LLVM_ROOT/bin/llc" \
  -O2 -mtriple=riscv32 -mattr=+m \
  -NZDC+NEMESEC=kernel -RASM=kernel:orig+dmr \
  build/quickstart/kernel.ll \
  -o build/quickstart/kernel.hardened.s
Output: build/quickstart/kernel.hardened.s
