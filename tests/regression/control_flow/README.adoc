= Control-flow regressions

These fault-free cases check returned values and observable branch effects
against constant oracle tables. Each successful execution exits with `42` and
no standard output; an incorrect result exits with `17`. Inputs and branch
effects are volatile, and protected functions are not inlined.

[cols="1,3,3",options="header"]
|===
|Case |Inputs and paths |Independent oracle

|`diamond`
|Inputs `-7, 0, 4, 9, 12` cover negative, odd and even branches, followed by
both sides of a second diamond and their common return.
|Results `24, 13, 21, 28, 27`; effects `12, 16, 16, 10, 12`.

|`edges`
|Inputs `0, 1, 2, 3, 6, 9` take and fall through successive conditional
branches, including the isolated `value == 6` path.
|Results `2, 5, 4, 18, 34, 36`; effects `12, 9, 12, 2, 16, 2`.

|`early_returns`
|Inputs `-5, 0, 1, 4, 9` reach every return in `control_early`; inputs
`12, 9, 4, 1, 0` exercise the differently shaped `control_classify` function.
Both protected functions are alternated three times in one translation unit.
|Early results `16, 7, 5, 14, 23` and effects `3, 5, 11, 11, 7`;
classifications `17, 19, 9, 10, 3`.

|`short_circuit`
|Inputs `0, 1, 2, 3, 4, 5, 8` cover skipped and evaluated right operands of
both `&&` and `||`. A protected probe records its calls in a base-three
accumulator, so correct return values alone cannot hide extra calls.
|Results `13, 18, 13, 12, 13, 12, 13`; effects `0, 2, 3, 17, 21, 25, 37`.

|`loop_values`
|Trip counts `0, 1, 2, 5, 9` exercise the loop preheader, backedge and exit
while two independently updated values stay live across iterations.
|Results `32, 43, 63, 119, 219`; effects `0, 5, 7, 19, 33`. The final
loop state is `3 + 2 * count`; odd iterations add and even iterations XOR
the explicitly determined sequence `3, 6, 9, ...` into the accumulator.

|`break_continue`
|Limits `0, 1, 3, 4, 5, 9` cover nested-loop entries, both `continue`
statements, the inner `break`, the outer `break` and natural loop exits.
|Results `1, 18, 52, 96, 126, 126`; effects `0, 22, 45, 65, 87, 87`.
Before the outer break, outer iterations contribute `17, 34, 0, 44, 30`
to the initial sum of one.
|===

The default matrix covers RV32 and RV64, the unprotected reference and every
supported data-flow/control-flow protection combination with coarse-grained
scheduling. Machine-instruction verification is requested separately from
functional execution. These checks do not inject faults or measure detection
coverage.

[source,sh]
----
python3 tests/regression/run.py --case 'control_flow/*'
----
