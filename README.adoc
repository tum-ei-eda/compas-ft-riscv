== Brief

Repo to house SIHFT passes for LLVM to create COMPAS, a compiler that adds fault tolerance on instruction level for RISCV 32/64 targets.
COMPAS is implemented such that it can be used as patch for the RISC-V LLVM toolchain.

== User Guide

Detailed instructions on compiler installation and usage can be found in link:docs/manual/[`docs/manual`]. We provide the manual as PDF.

The manual provides details on how to install LLVM compiler with our SIHFT passes. Further, the manual provides usage instructions on how to harden a given C/C++ project using SIHFT transformations.

See link:docs/rsm-layering.adoc[RSM instruction selection] for composing signature coverage of original instructions, DMR instructions and balance checks through per-function protection selections.

.Docs outdated? Rebuild them like so...
[example%collapsible]
====
After cloning the repo, run the following command from the repository root to generate the user manual with `latexmk`. The `-cd` option resolves inputs and figures relative to `docs/manual/src`; the generated PDF is written to `build/manual/main.pdf`.
[,bash]
----
latexmk -cd -pdf -outdir="$(pwd)/build/manual" docs/manual/src/main.tex
----

To generate the versioned PDF and HTML used by GitHub Pages, install `latexmk`, `texlive-latex-extra`, `texlive-fonts-recommended`, `pandoc`, and `poppler-utils`, then run:
[,bash]
----
sh docs/manual/generate.sh
----
The output is written to `build/manual/site`. Open `build/manual/site/index.html` to preview the site.
====
